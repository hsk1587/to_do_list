# To Do List

바닐라 HTML/CSS/JavaScript로 만든 간단한 할 일 목록 앱입니다.

## 주요 기능

- 할 일 추가 (입력 후 버튼 클릭 또는 Enter)
- 할 일 완료 체크
- 할 일 삭제
- 전체 / 진행중 / 완료 필터링
- 완료된 항목 일괄 삭제
- 브라우저 `localStorage`를 이용한 데이터 저장 (새로고침해도 유지)

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.

GitHub Pages: https://hsk1587.github.io/to_do_list/

## 파일 구조

```
├── index.html   # 화면 구조
├── main.js      # 할 일 추가/삭제/필터 등 동작 로직
└── style.css    # 스타일
```
